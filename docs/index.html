Projeto de portfólio · roda local

Painel Macroeconômico

Séries temporais do SGS, o sistema do Banco Central do Brasil — juros, inflação, câmbio, atividade e crédito — com resumo automático e assistente conversacional num modelo que roda na própria máquina.

As duas páginas abaixo são estáticas e abrem direto no navegador. Para rodar com dados ao vivo, buscando as séries na API do Banco Central, o repositório traz as instruções — são quatro comandos a partir de pnpm install.
